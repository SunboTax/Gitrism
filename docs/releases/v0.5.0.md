# Gitrism 0.5.0

Native Neovim history browsing and current-line attribution in both editors.

## Changes

- Browse commit graphs inside Neovim with branch/merge lanes, incremental loading, commit-message filters, and rename-aware file history. Open commit summaries and patches on demand, with detail splits that adapt to terminal width.
- Show the cursor line's last change by default in VS Code and Neovim: author, date, short commit hash, and message. Annotations follow the cursor, clear on line changes, and discard obsolete query results.
- Query only the selected line for current-line attribution. VS Code's whole-file annotation limit no longer blocks current-line attribution in large files.
- Keep function/class attribution optional: **Gitrism: Toggle Function Attribution** in VS Code, and `:GitrismAuthors` in Neovim.
- Offer the shared graphical management workspace through the explicit `:GitrismWeb` command, with local access tokens and file/worktree opening in Neovim.

## Getting started

- **VS Code:** install `gitrism-0.5.0.vsix` using **Extensions: Install from VSIX...**, then reload the window. For Remote SSH, install it on the remote Extension Host.
- **Neovim:** follow the [setup guide](https://github.com/SunboTax/Gitrism/blob/v0.5.0/docs/neovim.md), then run `:Gitrism`. Press `Enter` for details, `p` for a patch, `L` for more history, and `q` to return.

Native Neovim features require Neovim 0.10+ and Git 2.25.1+. They need no Node.js, build step, browser, or background service. The optional browser workspace requires Node.js 22+ and a built checkout.

## Upgrade notes

Current-line attribution now defaults to enabled; function/class CodeLens defaults to disabled. Existing explicit settings still apply. Toggle line annotations with **Gitrism: Toggle Inline Blame** or `:GitrismToggleBlame`.

Unsaved buffers do not show attribution. The terminal interface focuses on history and attribution; staging, commits, and history mutations remain in VS Code and the optional browser workspace.

## Validation

All 53 automated tests passed, including real Neovim 0.10.4 integration, different authors within one function, stale query handling, merge topology, file renames, and browser workflows.
