# Gitrism 0.6.0

Verified Cursor support using the same VSIX as VS Code, with local and Remote SSH installation guidance.

## Changes

- Validate the packaged extension in official Cursor 3.26.16 on Linux x64, locally and in a real Remote SSH workspace.
- Verify branch/merge graphs, focused keyboard navigation, the bottom panel, dark/light and both high contrast themes, and native revision diffs.
- Verify current-line attribution and optional function/class CodeLens, including different authors within one function.
- Add an isolated Cursor host test with screenshots and machine-readable results, plus a local/SSH setup and troubleshooting guide.

## Install and upgrade

Use **Extensions: Install from VSIX...** in VS Code or Cursor with `gitrism-0.6.0.vsix`. In an SSH window, install Gitrism on the remote Extension Host. Existing settings continue to apply. See the [Cursor guide](https://github.com/SunboTax/Gitrism/blob/v0.6.0/docs/cursor.md) for details.

The SSH acceptance run used Cursor Remote - SSH 1.1.16 against an isolated Linux endpoint on the same machine. Other operating systems, remote transports, and Cursor AI/agent features were not validated in this release.

## Validation

All 53 regression tests passed, including real Neovim and Chrome workflows. Packaged Cursor host checks passed locally and over SSH, covering the features listed above.
