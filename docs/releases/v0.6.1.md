# Gitrism 0.6.1

Configure HTTP and SOCKS5 proxies directly from the Git workspace toolbar.

- Choose existing Git/system settings, a custom proxy, or a direct connection for fetch, pull, push, and sync.
- Route HTTPS and OpenSSH remotes through HTTP or SOCKS5 proxies, preserving Git credentials, SSH identities, host-key checks, and HTTPS certificate verification.
- Show the Git host and explain loopback addresses in remote workspaces. Save editor settings per workspace; browser settings apply to the current service session.
- Localize controls in English, Simplified Chinese, and Traditional Chinese, with keyboard navigation and a layout for narrow windows.

A proxy endpoint must already be running and reachable. Proxy URLs with passwords or tokens are rejected. Authentication remains managed by Git; this update does not add an editor sign-in flow.

Install `gitrism-0.6.1.vsix` with **Extensions: Install from VSIX...**. For Remote SSH, install on the remote Extension Host. See the [network proxy guide](https://github.com/SunboTax/Gitrism/blob/v0.6.1/docs/network-proxy.md).
