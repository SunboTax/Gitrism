# Gitrism 0.6.2

Fix editor Git authentication and flickering line attribution.

- Use configured Git credential helpers without forcing credential managers into noninteractive mode. When credentials are missing, VS Code and Cursor can request GitHub sign-in or show masked credential prompts for other hosts.
- Use a fresh editor AskPass channel for each remote operation, avoiding stale inherited editor sockets. Remote editor operations allow up to five minutes, including authentication.
- Keep line attribution visible during repository refreshes and horizontal cursor movement. Unchanged results no longer redraw; changing lines or editing the file still clears obsolete attribution.

Install `gitrism-0.6.2.vsix` with **Extensions: Install from VSIX...**, then reload the window. For Remote SSH, install on the remote Extension Host. Existing SSH keys, agents, credential helpers, and proxy settings continue to apply. See the [authentication guide](https://github.com/SunboTax/Gitrism/blob/v0.6.2/docs/authentication.md).
